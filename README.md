# 快递聚合

一个纯本地的快递取件助手：自动读取手机收件箱里的快递短信，解析出取件码、驿站、快递公司，统一生成卡片——不用再翻短信、开多个 App 查快递。

## ✨ 功能

- 📦 **自动聚合**：扫描收件箱里的快递短信（菜鸟、丰巢、兔喜、顺丰、京东、中通、韵达、极兔等），自动提取取件码、取件地点、快递公司
- 🔒 **纯本地**：所有解析在手机本地完成，短信不上传、不存原文、不联网，数据只留在你设备里
- 🗓 **读取周期**：默认只读近 14 天，可在「设置」里改（7 天 / 14 天 / 30 天 / 180 天 / 自定义）
- 📇 **卡片管理**：点卡片展开看完整信息，点右上角标签标记已取/未取
- 🔍 **智能解析**：支持多种取件码格式——`取件码：XXX`、`凭 XXX 取件`、分段码 `1-2-3004`、带括号码 `【XXX】`

## 📥 下载安装

1. 下载 apk（从 [Releases](../../releases) 或分享链接）
2. 手机打开「允许未知来源应用安装」（设置 → 安全/隐私）
3. 点击 apk 安装

> 仅支持 Android 6.0（API 23）及以上。

## 📖 使用

1. 打开 App，首次会请求**短信读取权限**——这是自动识别快递短信的必要权限，可点「我们为什么要获取读取您短信的权限？」查看说明
2. 授权后，App 自动扫描收件箱，生成快递卡片
3. **点卡片主体** → 展开看完整信息（公司 / 地点 / 取件码 / 送达时间）
4. **点右上角「未取」标签** → 标记为已取（置灰 + 删除线）
5. 以后每次打开 App 自动刷新，新快递直接进列表

底部导航：
- **我的快递** — 快递卡片列表
- **设置** — 读取周期等选项

## 🔐 隐私

- 短信**只在手机本地处理**，不上传云端、不外发、不保存原文
- 只扫描含快递关键词（取件 / 凭 等）的短信，其余短信会自动过滤，不读取私密短信
- 数据存在手机本地，卸载 App 即清除

## 🛠 技术栈

- Flutter（Dart）+ Material 3
- telephony（读短信收件箱）+ permission_handler（权限申请）+ sqflite（本地存储）
- 纯前端，无后端依赖，离线可用

## 📝 说明

- 仅识别快递取件短信，不支持物流轨迹查询，手动勾“已取”“未取”，无法与联网应用同步
- 取件码识别依赖正则规则，少数非标准格式可能识别为「未知取件码」，后续会优化
- 下载渠道暂不通过 Google Play和其他app商店，仅通过 apk 分发
